# Football Club Data Analysis

This project analyses football club performance data to identify trends in results, player performance, and team statistics.

## Objective

To practise the complete Data Science workflow: data cleaning, exploratory data analysis, SQL queries, visualisation, and insight generation.

## Tools Used

- Python
- pandas
- NumPy
- Matplotlib
- Seaborn
- SQL
- Jupyter Notebook

## Project Workflow

1. Collected and explored the football dataset.
2. Cleaned missing values, duplicates, and incorrect data types.
3. Used SQL and pandas to analyse team and player performance.
4. Created visualisations to identify patterns and trends.
5. Summarised the main insights and conclusions.

## Key Questions

- Which players or positions contribute most to team performance?
- How do results change across home and away matches?
- Which metrics are most strongly related to winning matches?
- What trends can be identified across the season?
